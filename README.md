# us-accidents-dashboard
# 🛣️ Dashboard Accidents de la Route (US Accidents)

Tableau de bord interactif développé avec **Python** et **Dash**, permettant d'analyser un large jeu de données d'accidents de la route aux États-Unis (dataset Kaggle US Accidents) : répartition géographique, évolution temporelle, causes fréquentes et profils des victimes.

## 🎯 Objectifs

- Explorer visuellement un jeu de données volumineux d'accidents routiers
- Identifier les tendances par région, période, type de route et conditions météo
- Fournir un outil d'aide à la décision pour la sécurité routière

## ✨ Fonctionnalités

- **KPIs clés** : total des accidents, nombre de victimes, décès, blessés
- **Filtres** : région, année, type de route, conditions météo
- **Visualisations** :
  - Carte de répartition géographique des accidents
  - Évolution mensuelle du nombre d'accidents
  - Histogramme des causes les plus fréquentes
  - Diagramme de répartition par type de véhicule
  - Heatmap par heure de la journée et jour de la semaine
- Application restructurée en version multi-pages pour une navigation plus claire

## 🛠️ Technologies

- Python
- Dash / Plotly
- Pandas

## 📊 Jeu de données
